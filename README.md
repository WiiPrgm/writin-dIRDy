# writin-dIRDy
This is a homebrew exploit for the Wii Dev Kit menu (known internally as Boot-IRD). It currently requires a save file with the title id of RABA, but this can easily be modified and will be modifiable in future releases.

Place the .raw SD card image in the same directory as writin_dirdy.py along with your .elf or .dol Wii homebrew file. Run the script and write the resulting .raw file to an SD card using a disk imaging program. Dragging and dropping files onto an SD card will not work.

Place the SD card in your dev console, navigate to the Save Data screen and attempt to restore the data for RABA. Exploit will launch the executable baked into the SD card image.

See file 'exploit details' for info on how this works. AI wrote the explanation.
